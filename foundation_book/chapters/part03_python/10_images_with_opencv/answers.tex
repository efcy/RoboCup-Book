  \item It returns \texttt{None} (with only a warning), and later calls fail with confusing errors. The program should test for \texttt{None} and stop with a clear message.
  \item In HSV the colour type (hue) is separate from brightness, so one narrow hue range covers the ball in light and in shadow; in BGR all three channels change with the light. Red lies at both ends of the hue circle ($0$ and $179$), so it needs two ranges.
