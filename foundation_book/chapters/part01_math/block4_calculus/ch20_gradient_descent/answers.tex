  \item $L'(0)=-24$, so $w_1=0+0.05\cdot 24=1.2$. The true minimiser is $w=3$.
  \item (a) Convergence is correct but very slow. (b) Steps overshoot the minimum, the iterates oscillate or diverge.

x, eta = 0.0, 0.25
