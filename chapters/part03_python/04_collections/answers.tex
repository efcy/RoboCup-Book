\begin{verbatim}
lines = ["k1,1.18,30", "nao,0.57,5", "t1,1.18,30"]
rows = []
for line in lines:
    name, h, w = line.split(",")
    rows.append({"name": name, "h": float(h), "w": float(w)})
rows.sort(key=lambda r: r["name"])           # secondary key first
rows.sort(key=lambda r: r["h"], reverse=True)    # stable sort
print([r["name"] for r in rows])             # ['k1', 't1', 'nao']
\end{verbatim}
  Sorting is stable: equal heights keep the order of the earlier sort. Alternatively use one key with a tuple, \verb!key=lambda r: (-r["h"], r["name"])!.
