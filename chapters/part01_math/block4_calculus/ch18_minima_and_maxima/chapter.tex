\bookchapter{Minima and maxima}\label{ch:minmax}

\section*{Explanation}
At a smooth peak or valley the tangent line is horizontal, so the derivative is zero. Points where $f'(x)=0$ are called \emph{critical points}. To decide what kind of point it is, look at the second derivative:
\begin{itemize}
  \item $f''(x)>0$: the graph curves upward, so it is a \textbf{local minimum}.
  \item $f''(x)<0$: the graph curves downward, so it is a \textbf{local maximum}.
  \item $f''(x)=0$: the test is inconclusive.
\end{itemize}
A \emph{global} minimum is the lowest value of the function overall, a \emph{local} minimum is only lowest in its neighbourhood.

\textbf{Recipe:} (1) compute $f'$, (2) solve $f'(x)=0$, (3) classify using $f''$, (4) compute the function value.

\begin{example}
$f(x)=x^2-4x+5$. Then $f'(x)=2x-4=0$ gives $x=2$. Since $f''(x)=2>0$, it is a minimum, with value $f(2)=1$.
\end{example}

\begin{example}
$f(x)=x^3-3x$. Then $f'(x)=3x^2-3=0$ gives $x=\pm1$. We have $f''(x)=6x$, so $f''(1)=6>0$ (local minimum, $f(1)=-2$) and $f''(-1)=-6<0$ (local maximum, $f(-1)=2$).
\end{example}

\begin{aibox}
Training a network means finding weights that make the loss as small as possible, which is a minimum problem. For a loss like $L(w)=(w-3)^2+2$ the minimum is at $w=3$.
\end{aibox}

\section*{Practice problems}
\begin{enumerate}[label=\textbf{\thechapter.\arabic*}]
  \item Find the minimum of $f(x)=x^2-6x+10$ and its value.
  \item Find the maximum of $f(x)=-x^2+4x$ and its value.
  \item Find and classify all critical points of $f(x)=x^3-12x$.
  \item You have $40$ m of fence to enclose a rectangular robot arena (fence on all four sides). Find the side lengths that give the largest area. (Hint: if one side is $x$, the other is $20-x$.)
  \item Find the minimum of $L(w)=(w-3)^2+2$ using derivatives.
  \item Consider $f(x)=x^3$. Show that $f'(0)=0$, but $x=0$ is neither a minimum nor a maximum.
  \item[\textbf{\thechapter.7}$\star$] A sensor reading is modelled by $L(c)=\sum_{i=1}^{3}(c-x_i)^2$ with measurements $x_1=2,\,x_2=4,\,x_3=9$. Find the value of $c$ that minimises $L$. What statistic is it?
\end{enumerate}
