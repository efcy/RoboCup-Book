  \item Because the ball is rare ($10\,\%$ of the frames). Many more frames without a ball exist, so even $2\,\%$ false alarms give $18$ false detections, compared with $95$ true ones. $P(\text{ball}\mid\text{det})$ depends on the prior.
  \item Example:
\begin{verbatim}
import random
det_total = 0
det_ball = 0
for _ in range(1000000):
    ball = random.random() < 0.10
    p_det = 0.95 if ball else 0.02
    if random.random() < p_det:
        det_total += 1
        det_ball += ball
print(det_ball / det_total)
\end{verbatim}
  The result is close to $0.841$.
