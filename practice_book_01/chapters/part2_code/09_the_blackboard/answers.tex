\begin{enumerate}[label=\textbf{\ansnum.\arabic*}]
  \item It raises \emph{cycle through A} (or B): to run $A$ it must first run $B$, which needs $A$. The data flow has no start. If a module really needs a value of the previous cycle, make that explicit: a separate representation such as \texttt{LastMotionCommand} that a module at the start of the cycle provides from a stored copy. B-Human calls such representations ``previous'' or uses a special declaration.
  \item
\begin{verbatim}
def run_cycle_checked(order, bb):
    for m in order:
        before = {k: id(v) for k, v in bb.snapshot().items()}
        m.update(bb)
        after = bb.snapshot()
        for rep in m.provides:
            if rep not in after or id(after[rep]) == before.get(rep):
                raise RuntimeError(f"{type(m).__name__} did not write "
                                   f"{rep.__name__}")
\end{verbatim}
  \item
\begin{verbatim}
class View:
    def __init__(self, bb, allowed_read, allowed_write):
        self.bb, self.r, self.w = bb, set(allowed_read), set(allowed_write)
    def get(self, kind):
        if kind not in self.r:
            raise PermissionError(f"{kind.__name__} not in requires")
        return self.bb.get(kind)
    def set(self, value):
        if type(value) not in self.w:
            raise PermissionError(
                f"{type(value).__name__} not in provides")
        self.bb.set(value)
\end{verbatim}
\verb!run_cycle! then calls \verb!m.update(View(bb, m.requires, m.provides))!.
  \item The recorder stores references to the objects of each cycle (or pickles them). If a module changes an object in place, an object that was already handed to the recorder, the debug server or the other thread changes too, and the log shows values that never existed at that time. New objects every cycle make each snapshot a true picture.
  \item SensorInput first, CommandOutput last, Behaviour before CommandOutput; BallDetector and Localisation in either order: (SensorInput, BallDetector, Localisation, Behaviour, CommandOutput) and (SensorInput, Localisation, BallDetector, Behaviour, CommandOutput).
\end{enumerate}
